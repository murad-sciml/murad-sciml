# Hi, I'm Murad Ali Khan 👋

**PhD Researcher in AI for Materials Discovery** · Jeju National University, South Korea · Team Lead, Big Data Research Center

I build machine learning methods that help scientists and engineers reach target material properties with fewer experiments, especially when data is small, noisy, or comes from many sources.

## 🔬 Research Focus

- **Inverse design**: recommending material compositions and processing conditions for target properties
- **Learning from limited data**: transfer learning, cross-domain knowledge transfer, and data augmentation
- **AutoML and ensemble learning** for robust property prediction
- **Anomaly detection and forecasting** for process, energy, and sensor data
- **Virtual sensors** for spatial-temporal environmental monitoring
- **Federated learning** for collaborative, privacy-preserving materials discovery
